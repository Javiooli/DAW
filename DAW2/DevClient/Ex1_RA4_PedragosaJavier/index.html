Petición AJAX

Cómo funciona:
Al pulsar el botón se envía una petición GET asíncrona al archivo saludo.txt. El navegador no se bloquea, y cuando el servidor responde, se inserta el mensaje en el div.
Pulsa el botón para cargar el mensaje desde el servidor
// Crear objeto XMLHttpRequest
const xhr = new XMLHttpRequest();

// Configurar petición GET asíncrona
xhr.open('GET', 'saludo.txt', true);

// Definir qué hacer cuando responda
xhr.onload = function() { ... }

// Enviar petición
xhr.send();
